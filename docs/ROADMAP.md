# Roadmap

The released baseline is 2.0.8. Work is guided by the remaining beta acceptance gaps, not by the older 2.0 planning notes.

- Investigate the intermittent multiplayer standing-passenger position reset.
- Complete fresh multiplayer bus, save/reload and loose-item right-click acceptance on the current payload.
- Complete trait behavior acceptance, including a server with the Java panic adapter.
- Recheck normal hosted/Steam-server setups, ordinary player checksums, broader dependency compatibility and physical controller use.
- Continue Animals support on `codex/animals-support`; require full implementation and native single-/multiplayer acceptance before merging it.
- Welcome vehicle support add-ons through the existing profile/spec pipeline.

The [2.0 plan](history/PLAN-2.0.md) and [older development notes](history/ROADMAP-20261007.md) are historical records. They do not state the current release status. See [compatibility](COMPATIBILITY.md) for current limitations.
