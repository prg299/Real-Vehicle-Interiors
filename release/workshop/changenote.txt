2.0.18 - Optional vehicle packs

- ZombieBuddy is now the only required mod. Use the supported vanilla vehicles without installing any car packs or damnlib.
- Install any combination of supported KI5 packs. Each pack still needs its own dependencies; missing vehicle packs are skipped.
- Interior benches use the game's chair animation when damnlib is absent. Enabled damnlib retains its existing seated pose.

Existing vehicle, furniture, loot and utility IDs are unchanged. This update does not require starting a new save.
