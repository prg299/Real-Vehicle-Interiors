2.0.20 - Native interior movement

- Walking, running and turning now use the game's normal movement states and animation blending, including native stopping travel and aiming/strafe input.
- Fixed automatic approaches being cancelled when a turning stride briefly touches a wall.
- Fixed right-click furniture menus failing when there is no underlying world object to pick.
- Fixed re-entry being cancelled by a tiny pathfinding step when already standing at the door.

Existing vehicle, furniture, loot and utility IDs are unchanged. This update does not require starting a new save.

Restart the game after updating and approve the updated Java component in ZombieBuddy when prompted.
