Walk around inside KI5 campers, B700 buses and F700 box trucks. Your interior and supplies travel with the vehicle.

[h2]How it works[/h2]
The roof and upper walls hide while you're inside. Move normally and right-click furniture to use it.
[list]
[*] Sleep, cook, wash and manage power, water and heating.
[*] Store supplies, place items and rearrange custom RV furniture.
[*] Rename your vehicle and paint its interior.
[/list]

[h2]Requirements[/h2]
[b]Build 42.21[/b], KI5 Campers, '87 Ford B700, ZombieBuddy and damnlib.

ZombieBuddy loads the Java code for roof cutaways and normal standing/walking animations. Approve the Java file when prompted.
MP trait effects also require ZombieBuddy to load this mod's Java code on the server.

[h2]Incompatibilities[/h2]
Not compatible with [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3809306528]Project Viewpoint[/url].

[h2]Beta & saves[/h2]
Multiplayer is experimental. MP removal is untested.

Should be safe to add to and remove from existing saves. [b]Back up first[/b]; custom furniture and stored items may disappear.

AI was used to make this mod. If you have a problem with that, don't download it.

[i]Submods supporting other vehicle mods are welcome.[/i]
