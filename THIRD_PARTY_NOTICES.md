# Third-party notices and asset provenance

The MIT license covers this project's authored contributions. It grants no rights to Project Zomboid, ZombieBuddy, damnlib, KI5 vehicle mods, Companion Dogs, Steam SDKs, or their trademarks. Obtain those projects independently under their own terms.

- **Project Zomboid / The Indie Stone:** no game JARs, extracted classes, native libraries, game textures or original shader files are distributed here. Java compiles against a locally installed game. `tools-src/shaders/*.json` stores the mod's shader edits and line references into an exact local game shader version. `scripts/prepare-shaders.py` validates the original hash and reconstructs the runtime shader under `build/`; those generated outputs incorporate game code and are not wholly MIT-licensed. Re-review the recipes after a game update.
- **ZombieBuddy:** external Java loader and API, Workshop `3619862853`. Its JAR is required locally and is not redistributed.
- **KI5 and damnlib:** original vehicle meshes, skins, scripts and animations remain external Workshop inputs. The mod references their identifiers. Authored interior shells and furniture are generated by `tools-src/blender/rv_kit.py`; vehicle layouts are in `tools-src/vehicles/specs/`. Cab closure contours use measured cross-sections to fit the lining to each body.
- **Sight geometry:** `MELens_VisionGeometry.lua` contains numerical opening bounds generated from local vehicle measurements and resolved script interaction areas by `tools-src/vehicles/vision_geometry.py`. Original game and dependency models, textures and scripts remain external.
- **Arcadia RV Interior:** Workshop `3773972040` was consulted for candidate vehicle identifiers in the fleet expansion. Its Lua, maps, scripts and artwork are not redistributed. Measurements use separately installed game/vehicle meshes; only authored layouts and interior shells ship here.
- **Companion Dogs:** optional on the Animals WIP branch, Workshop `3740052292`. Its code and artwork are not included.
- **Artwork:** the mod icon and poster reuse the current gameplay cover. Furniture/material masters and generation provenance are retained in `tools-src/art/`; runtime assets are in `mod/`. [Service furniture provenance](tools-src/art/utility-furniture-20261023.json) records the stretcher and equipment-cabinet icons, reused material masters, export sizes and TinyPNG compression.
- **Screenshots and recordings:** local native test captures, save data, Workshop receipts containing machine paths and promotional video masters are excluded from this source import. The existing Workshop preview and approved animated cover are retained without modification.

This is an independent community mod and is not affiliated with the game or dependency authors. Please preserve attribution when redistributing authored contributions.
